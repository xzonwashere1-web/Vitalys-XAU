# Vitalys XAU

Repository: [xzonwashere1-web/Vitalys-XAU](https://github.com/xzonwashere1-web/Vitalys-XAU)
Community: [Vitalys XAU Discord](https://discord.gg/yqnK2dpbty)

A community-maintained Xbox Achievement Unlocker fork created and maintained by Vitaly. It builds on the original [Xbox Achievement Unlocker](https://github.com/ItsLogic/Xbox-Achievement-Unlocker), created by Draff with contributions from its community. Original notices and licenses are retained in [LICENSE](LICENSE) and [LICENSE.MIT](LICENSE.MIT).

## Build

Open `Vitalys XAU.sln` in Visual Studio or JetBrains Rider with the .NET Windows desktop workload installed. The WPF project targets `net9.0-windows`.

## Related projects

- Original upstream source: https://github.com/ItsLogic/Xbox-Achievement-Unlocker
- Events data submodule: https://github.com/Fumo-Unlockers/XAU-Events
